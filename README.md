# ВоенКомис: Учёт призывников

Мобильное приложение для автоматизации учёта граждан призывного возраста в военкомате.

## Функционал

- **Добавление призывника** — ввод фамилии, имени, отчества, возраста
- **Выбор категории годности** — выпадающий список с вариантами А, Б, В, Г, Д
- **Автоматическая дата** — простановка текущей даты при добавлении
- **Просмотр списка** — отображение всех записей с подробной информацией
- **Счётчик записей** — автоматическое обновление количества добавленных граждан
- **Очистка полей** — автоматическая после добавления для быстрого ввода новых данных

## Как использовать

1. Запустите приложение на Android-устройстве
2. Заполните поля:
   - Фамилия
   - Имя
   - Отчество
   - Возраст
3. Выберите категорию годности из выпадающего списка
4. Нажмите кнопку **"ДОБАВИТЬ"**
5. Новая запись появится в списке в нижней части экрана
6. Счётчик автоматически обновится

## Технологии
- Java
- Android SDK
